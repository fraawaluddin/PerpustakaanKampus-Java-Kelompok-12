# Sistem Manajemen Perpustakaan Kampus

Sistem Manajemen Perpustakaan Kampus merupakan program berbasis Java yang dirancang untuk mengelola koleksi buku, lokasi penyimpanan, antrean peminjaman mahasiswa, serta riwayat transaksi. Program ini dibuat untuk menerapkan enam jenis struktur data dalam satu aplikasi dengan menu interaktif menggunakan `Scanner`.

### Keterangan Struktur Proyek

- **`main`**: Package yang berisi kelas utama `PerpustakaanKampus.java` untuk menjalankan program dan mengelola menu interaktif.
- **`model`**: Package yang berisi kelas `Antrean.java`, `Buku.java`, dan `Transaksi.java` untuk mendukung pengelolaan data program.
- **`test`**: Direktori yang disediakan untuk kode pengujian.
- **`README.md`**: File dokumentasi proyek.
- **`pom.xml`**: File konfigurasi proyek Maven.
- **`nbactions.xml`**: File konfigurasi aksi proyek untuk NetBeans.
